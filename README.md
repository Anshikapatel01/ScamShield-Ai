# ScamShield AI

An AI-powered multilingual scam and spam detection application designed to make digital communication safer and easier to understand.

## Planned Features

- Scam and Spam message detection 
- Green,orange and red risk levels
- Explainable detection results 
- Hindi, English, and Hinglish support
- Senior- friendly interface

Currently in development.
